📌 專案摘要 (Executive Summary)

東淦入職安全訓練評估系統 (JO-SED) 是東淦工程有限公司針對香港法定職安健規範（香港法例第 59 章《工廠及工業經營條例》）及國際標準管理體系（ISO 45001 / ISO 9001 / ISO 27001）自主設計的無紙化治理方案。

本專案將地盤新進人員「地盤入職安全培訓評估紀錄」全面數位化，以 Streamlit 原生架構、動態 Secrets 金鑰防護與受控 PDF 引擎 為基礎架構，在零外置資料庫、零個人資料持久化（Zero-Data-Retention）的前提下，實現「工友填報 ➔ 即時自動評分 ➔ 受控 PDF 產生 ➔ 後端自動直送 SED 郵箱 ➔ 本地離線備份」的全自動安全合規閉環。

🏛️️ 流程生命週期與治理閉環 (Workflow Lifecycle)

傳統紙本地盤培訓紀錄常面臨「紙本易污損、字跡潦草、缺乏防偽時間戳、審計調閱繁複」等痛點。JO-SED 透過兩階段嚴謹架構達成 100% 封閉式治理閉環（Closed-Loop Governance）：

第一階段・驗證
門禁金鑰核驗
支援 URL 參數 (?key=...) 直達或通行碼輸入，杜絕未授權存取。
第一階段・考核
安全試題測驗
填寫姓名、工人註冊證並完成 5 條地盤安全評估試題，勾選個人誠信聲明。
第二階段・評定
即時自動評分
即時計算得分（最少答對 3 條判定為 PASS / FAIL），並產生合規報告。
第二階段・存證
受控 PDF 繪製
自動嵌入 HKT (UTC+8) 時間戳、受控編號 JO-SED-REC-2026-V1 與法律聲明。
第二階段・閉環
一鍵自動歸檔
後端 SMTP 自動直寄 SED 郵箱，徹底杜絕漏寄附件與人為疏失。

📋 業務四部曲對照表 (Governance Matrix)

階段 責任角色 承載技術 處置動作與審計紀錄
第一部分：身份識別 新入職員工 / 工友 Web 門禁模組 驗證合法存取權限，填寫姓名、工人註冊證號碼及所屬組別。
第一部分：安全考核 新入職員工 / 工友 動態題庫引擎 完成個人防護裝備 (PPE)、高空作業、意外處理與危害通報等核心職安健試題。
第二部分：能力評定 評估系統核心 確定性規則演算法 執行 60% 門檻判定（≥3 題為合格），即時反饋考核狀態，落實 ISO 45001 Clause 7.2。
第二部分：文件化紀錄 受控 PDF 引擎 FPDF (Noto Sans TC) 自動生成含公司抬頭、受控文件編號與香港標準時間 (HKT) 之不可竄改 PDF 報告。
第二部分：自動歸檔 安環組 (SED) / 系統 Python SMTP / M365 一鍵將 PDF 報告直送安環組審計郵箱，並提供工友 WhatsApp 備用通訊確認機制。

⚙️️ 技術亮點 (Technical Implementation)

1. 零資料留存架構 (Zero-Data-Retention)

無外置資料庫，所有個資僅於記憶體暫存用於即時渲染 PDF，作業完畢立即銷毀，徹底杜絕雲端資料庫洩漏風險。

2. 動態 Secrets 機密隔離

題庫答案、門禁通行碼與 SMTP 寄件憑證均獨立儲存於雲端環境變數，原始碼公開倉庫 100% 零機密暴露。

3. 輸入消毒與防注入防禦

嚴格限制輸入字元長度並自動清理換行及特殊符號，防範 XSS、HTML 注入與檔名穿越等潛在安全風險。

4. 時區標準化 (Timezone Normalization)

底層全面鎖定香港標準時間（UTC+8 HKT），確保法律免責聲明與培訓能力紀錄完全符合法定審計查驗。
